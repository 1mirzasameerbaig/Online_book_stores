# Bookstore Data Analysis using PostgreSQL

# Project Overview
This project is part of my 30 Days of Advance SQL Practice Challenge, focused on developing practical SQL skills through a bookstore database.

Using PostgreSQL, I created and analyzed three relational tables — Books, Customers, and Orders — to explore book inventory, customer purchasing behavior, sales performance, and revenue.

# Tools Used
Database: PostgreSQL
Language: SQL
Data Import: CSV files
Platform: GitHub

# Database Structure
Books: Book titles, authors, genres, publication years, prices, and stock.
Customers: Customer names, contact details, cities, and countries.
Orders: Customer orders, book references, order dates, quantities, and total amounts.

The tables are connected through primary keys and foreign key relationships.

# Key Business Questions
This project answers practical bookstore business questions, including:
1. Retrieve books by genre and publication year.
2. Identify the most and least expensive books.
3. Calculate total available stock and average book prices.
4. Find customers who placed multiple orders.
5. Identify the most frequently ordered books.
6. Calculate total books sold by genre and author.
7. Determine top-spending customers and total revenue.
8. Analyze orders placed during a specific period.
9. Calculate remaining inventory after accounting for orders.

# SQL Concepts Practiced
Basic queries using SELECT, WHERE, DISTINCT, and ORDER BY
Aggregate functions: SUM(), AVG(), MAX(), and COUNT()
GROUP BY and HAVING
INNER JOIN and LEFT JOIN
Sorting and filtering with LIMIT and BETWEEN
STRING_AGG() and COALESCE()
Primary keys, foreign keys, and relational database design
CSV data imports using PostgreSQL's COPY command
